# Internal Reference Site
 
Static multi-page internal reference website.
 
## Pages
 
- Home
- Getting Started
- Guidelines
- FAQ
 
## Technology
 
- HTML5
- CSS3
- Vanilla JavaScript
 
## Local development
 
No build step is required.
 
Open `index.html` in a browser, or use a local
development server such as VS Code Live Server.
 
## Deployment
 
The site can be deployed to any static hosting service
or internal web server.
